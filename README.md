# Portfólio — Vanessa Barbosa

Site portfólio pessoal desenvolvido para atividade acadêmica com **Vite + React + TypeScript**.

## Tecnologias

- React
- TypeScript
- Vite
- HTML semântico
- CSS responsivo
- Git

## Seções

- Início
- Sobre
- Projetos e habilidades
- Mídia
- Contato

O projeto possui navegação responsiva para celular, imagem, vídeo e animação CSS (`pulse`).

## Como executar

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Personalização antes da entrega

1. Substitua `public/profile.svg` pela sua foto real, mantendo o nome `profile.jpg` e alterando os dois `src` no `src/App.tsx`, ou mantenha o SVG se a atividade aceitar uma imagem ilustrativa.
2. Troque `seuemail@exemplo.com` pelo seu e-mail.
3. Troque os links do GitHub e LinkedIn pelos seus perfis.
4. Se desejar, ajuste os textos dos projetos.

## Git

O trabalho deve ficar em um repositório exclusivo para este portfólio. Faça pelo menos três commits claros, por exemplo:

```bash
git init
git add .
git commit -m "feat: cria estrutura inicial do portfólio"

git add .
git commit -m "feat: adiciona seções e projetos"

git add .
git commit -m "style: adiciona responsividade e animações"
```
